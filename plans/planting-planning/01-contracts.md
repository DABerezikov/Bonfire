## Данные и инварианты

- RegionId, SeasonalPlantingPlanId, PlannedBatchId — положительные типизированные ID.
- DateWindow — включительные DateOnly Start/End; Start ≤ End. Операции сдвига
  возвращают Result при переполнении календаря.
- DayRange — целые неотрицательные Min ≤ Max. None не равно 0.
- Прорастание G — от посева до всходов. Возраст A — от всходов до высадки.
- Пикировка P — интервал от всходов; закаливание H — длительность до высадки.
- Percentage: всхожесть в (0;100], потери в [0;100). Использовать decimal,
  чтобы избежать ошибок округления double при вычислении количества.
- Целевое количество растений и число семян — положительные целые с проверкой
  диапазона хранения. Нулевой/неизвестный процент не превращается в 100%.
- Место — OpenGround / Greenhouse / Windowsill, размещение — InGround / Container; без зодиака, отопления
  и погодного прогноза. Лунная группа — AboveGround / RootCrop / Unspecified.
  Class культуры не использовать как готовую лунную классификацию.
- Сорт не является владельцем CultureId. Партия хранит выбранные CultureId и SortId;
  допустимость пары проверяется через существующие связи Plant при сохранении.
- Каждая партия имеет собственные даты, профиль, количество и выбор пользователя.
  Сезон не ограничивает все даты одним годом: подготовка может начаться в декабре.

Снимок профиля сохраняет значение, источник Culture/Sort/Batch и версию расчёта.
Для диапазонов повторно использовать существующие значения SortCharacteristicsValues;
не добавлять второй набор свойств прорастания/возраста на том же сорте.
Новые настройки сорта содержат только отсутствующие сейчас параметры.

## Наследование и ручные изменения

Приоритет: партия → сорт → культура. Диапазон — одно значение целиком.
Частично заполненный сортовой диапазон не достраивается другим источником молча.
Отсутствие обязательного значения даёт MissingInput с именем параметра.
Для необязательной операции нужны три состояния: наследовать, явно включить,
явно отключить. Одного Option для такого override недостаточно.

```text
Resolve(rangeOverride, sortRange, cultureRange):
    return match rangeOverride:
        Use(value) => ValidateComplete(value).WithSource(Batch)
        Inherit => match sortRange:
            Complete(value) => Success(value, Sort)
            Partial(value) => MissingInput("Уточните диапазон сорта", value)
            Absent => RequireComplete(cultureRange).WithSource(Culture)

ResolveOperation(override, inherited):
    return match override:
        Inherit => inherited
        Disabled => None
        Enabled(settings) => Some(Validate(settings))

DateWindow.Create(start, end):
    return start <= end ? Success(window) : Failure("Начало позже окончания")
```

Закрытые варианты с поведением — sealed-типы; Map, если понадобится, только
extension с исчерпывающим matching. Инертные дискриминаторы могут быть enum.

## Последовательность и проверки

Дополнение после анализа книги: способ выращивания — закрытые варианты
Transplant(TransplantWindow) и DirectSow(SowingWindow). Во втором варианте
возраст рассады, пикировка и закаливание отсутствуют как неприменимые, а не
MissingInput или нулевые значения. Место и способ размещения независимы
от способа. Для прямого посева потери означают потери после всходов до целевого
числа растений, без этапа пересадки; подпись не должна говорить «потери рассады».

Вегетация считается от всходов; альтернативных баз в новом расчёте нет.
Нормы урожая — кг/растение и кг/м²; старое YieldKg не получает базу автоматически.
Периоды цветения/плодоношения и жизненный цикл — по этапу 11; журнал сборов —
по этапу 10. Микрозелень и генерация повторных волн исключены.

```text
ValidateRequiredParameters(method, profile):
    match method:
        Transplant(window) => Require(window, profile.Germination, profile.Age)
        DirectSow(window) => Require(window, profile.Germination)
    // вегетация нужна для прогноза урожая; её отсутствие не запрещает план посева
```

## Условия и дополнительные контракты после окончательных ответов

«Контейнер» может находиться на подоконнике или в теплице, поэтому не делать
все четыре названия взаимоисключающими. Проектный контракт разделяет место
OpenGround/Greenhouse/Windowsill и размещение InGround/Container; UI показывает
понятные подписи и допустимые сочетания. На подоконнике требуется Container.
Размеры грядки — независимый снимок в метрах, ориентация рядов и отступы — явные
значения (этап 9). Журнал — отдельные положительные массы в кг (этап 10).
Идентичность многолетней посадки общая для сезонов, а не новая ежегодно (этап 11).
