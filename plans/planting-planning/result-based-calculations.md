# Исправление: расчёты через Result

01.11.2026. По замечанию владельца исключения убраны из управления ожидаемыми
отказами расчётов. Ветка feature/planning-results-without-exceptions.

- DecimalArithmetic выполняет точные промежуточные операции с BigInteger,
  проверяет представимость и округляет ToEven. Деление на ноль/выход за диапазон
  возвращают Failure, без возбуждения и перехвата арифметических исключений.
- BedCapacity, HarvestProjection, SeedQuantityCalculation и HarvestSummary
  распространяют Result. Число позиций/мест и преобразование double-размеров
  проверяются до ограниченной операции. Огромные отступы дают нулевую вместимость.
- HarvestSeasonSummary считает сезон в Domain; PlanningPresentation только
  форматирует Result. Отказ партии не фильтруется и не исчезает из сводки.
- Сравнение сбора с прогнозом использует проверяемое вычитание.
- RegionDefinition использует TryFindSystemTimeZoneById. Библиотечные команды
  обрабатывают Result сервисов без локального catch(Exception).
- Убраны искусственные throw в преобразовании отказов лунных рекомендаций.

В Domain/Application/Models/ViewModels обработчиков catch больше нет.
try/finally сброса IsBusy/флагов выбора сохранены: они не управляют отказами.
Адаптеры внешних библиотек, файлов, EF/SQLite и глобальные границы UI по-прежнему
преобразуют технические исключения внешнего API; расчёты через них не выполняются.

Red/Green: новый контракт арифметики и сезонной сводки. Матрица 31×31×4 = 3844
операций сравнивает результаты с .NET decimal, включая знаки, масштабы и крайние
значения. Обнаруженное отличие простой проверки диапазона для округляемой границы
устранено точным расчётом мантиссы. Тест FirstChanceException подтверждает, что
ожидаемые арифметические отказы не возбуждают даже перехваченных исключений.
Проверены очень большие/малые размеры и обычное преобразование 300×135 при 150 пкс/м.

Полный гейт: **1769/1769**, пять проектов: Models 817, Services 567,
ViewModels 344, Repository 35, SeedsFromViewModel 6. Схема и рабочая БД не менялись.
Сборка — 0 предупреждений/ошибок. Startup/exit прошёл планирование, журнал,
межсезонные посадки, обе библиотеки и возврат к семенам; HostDisposed=True.
