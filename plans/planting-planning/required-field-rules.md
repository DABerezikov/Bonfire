# Единые правила обязательных полей

У формы планирования один источник обязательности: `PlanningFieldRule` содержит
имя поля, условие IsRequired и проверку на существующем Result. Caption добавляет
звёздочку по IsRequired; IDataErrorInfo возвращает Error этого же правила;
проверка шага и сборка запроса используют его Validation. Независимые звёздочки
из подписей XAML удалены. Объяснение обозначения звёздочки остаётся обычным текстом.

Правила охватывают создание сезонного плана, культуру/сорт, условия, обе границы
рабочего периода, количество растений, условную геометрию и нормы урожайности,
агротехнические сроки, проценты, включённые операции и параметры жизненного цикла.
Необязательные диапазоны требуют обе границы, если пользователь начал их заполнять.
Отключённые поля сохраняют текст и не блокируют неприменимый сценарий.

Для агротехники проверяется эффективное значение: партия → сорт → культура через
существующий `PlanningParameters.ResolveRange`. Неполный сортовой диапазон не
подменяется культурным. Для процентов и норм учитываются настройки сорта/культуры.
0% потерь — заданное значение. Ручное число семян снимает обязательность процентов
одновременно с отметкой и ошибками полей. При смене культуры/сорта справочные
значения предыдущего выбора очищаются. Сохранённый снимок сразу снабжает редактор
своими эффективными значениями, пока перечитывается свежая справка.

Шаг «Параметры» проверяет обязательные поля до расчёта. Кнопка «Проверить и
рассчитать» открывает «Результат» только после полного успешного ответа Application,
с документом и рассчитанным/ручным числом семян. Прямой переход вкладкой это
ограничение не обходит. Отказ остаётся на параметрах с причиной; изменение ввода
снова блокирует результат до пересчёта. Выбор лунного дня возвращает к результату
после успешного пересчёта. Сохранение использует ту же проверку полноты результата.

Подсказка выбранной даты больше не предлагает сохранять неполный расчёт.
К недостающим данным количества семян можно перейти кнопками на шаге параметров.

Проверки: 1806/1806 (Models 838, Services 567, ViewModels 360, Repository 35,
SeedsFromViewModel 6). Проверены соответствие Caption/IsRequired/Error/Validation,
наследование, 0% потерь, ручной и автоматический режимы, геометрия, нормы,
условные операции, поля сезонного плана, запрет прямого открытия неполного
результата и согласованное изменение звёздочки/валидации в настоящем WPF.
