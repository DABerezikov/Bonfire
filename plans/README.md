# Планы рефакторинга

Дата фиксации: 24.10.2026. Исходный коммит: `8a51f5f`.

- [Исходный архитектурный план](refactoring-baseline.md) — проблемы, целевые слои и первоначальная последовательность.
- [Уточнённый план](refactoring-functional-domain.md) — актуальный план с целями владельца: богатые модели, декларативность, функциональный подход и явное отсутствие значений.
- [Карта доменных контрактов](domain-contracts.md) — владельцы данных, семантика посева и открытые вопросы.
- [Первый результат реализации](refactoring-progress.md) — изменения, TDD-проверки и оставшиеся границы.

При расхождениях приоритет имеет уточнённый план. Оба документа описывают
предстоящую работу; сохранение плана не означает реализации этапов.
Результаты этапов и доказательства проверок следует добавлять по мере выполнения.

Исходные проверки и ограничения: [матрица сценариев](../Tests/README.md),
[отчёт покрытия](../Tests/COVERAGE.md).
