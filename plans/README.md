Информационная панель семян показывает сорт и производителя в заголовке.
Общая панель характеристик семян и рассады сохраняет порядок редактора. Для диапазонов
только первое значение выводится как «от …», только второе — как «до …»;
два значения — через « - » (схема посадки — через « x »),
строки без значений скрываются вместе с подписями, без промежутков; нули видимы.
Пустое описание скрывается вместе со своим заголовком и рамкой.
Размер плода — необязательный целочисленный диапазон в сантиметрах, сохраняемый
в БД; [контракт, миграция и проверки](sort-fruit-size.md).
Редактор урожайности принимает запятую
и не более одного знака после неё; лишние знаки блокируют сохранение без округления.
Урожайность передаётся из TextBox в модель при потере фокуса: промежуточный ввод
«2,» сохраняется до завершения ввода дробной части.
Нечисловой текст урожайности проверяется до ConvertBack через ValidationRule:
ввод сохраняется в поле, ошибка блокирует сохранение без FormatException.
Поля редактора семян показывают текст ошибки в tooltip при Validation.HasError;
после исправления подсказка ошибки снимается.
Текст tooltip извлекается безопасным конвертером всей коллекции ошибок;
опустевшая коллекция возвращает null без обращения по индексу.
В редакторе схема посадки требует оба значения либо оба пустых поля; неполная
пара блокирует сохранение и отмечается ошибкой в обоих полях.
